Detailed Description

DipoleSource represents a magnetic dipole — the simplest model of a localized magnetic source (e.g. a small permanent magnet or coil).

The magnetic field it produces at any point r is:

B(r) = (mu0 / 4π) * [ 3(m·r̂)r̂ - m ] / |r|³

where: r = observation point - dipole position (displacement vector) r̂ = r / |r| (unit vector) m = magnetic dipole moment [A·m²] |r| = distance from dipole to sensor [m]
