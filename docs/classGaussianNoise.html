Detailed Description

GaussianNoise models additive white Gaussian noise (AWGN) on a 3-axis sensor.

In real magnetometers, electronic noise causes each measurement component (Bx, By, Bz) to be offset by a small random amount drawn from N(0, sigma²).

Each component is corrupted independently — this is the standard noise model for MEMS and fluxgate magnetometers.
