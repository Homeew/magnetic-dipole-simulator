Detailed Description

LMSolver implements the Levenberg-Marquardt (LM) algorithm — a standard method for nonlinear least-squares problems.

THE PROBLEM: Given noisy B measurements from N sensors, find the dipole parameters x = [px, py, pz, mx, my, mz] that minimise:

F(x) = 0.5 * sum_i ||B_predicted(x, sensor_i) - B_measured_i||²

This is nonlinear because B depends on x in a nonlinear way (1/r³, dot products).

THE METHOD (Levenberg-Marquardt): Each iteration solves the linear system:

(J'J + λI) Δx = -J'r

where: J = Jacobian matrix (how each residual changes with each parameter) r = residual vector (predicted - measured, for all sensors/components) λ = damping factor (controls the step size) Δx = parameter update to apply

  • If the new cost is lower → accept Δx, decrease λ (more like Gauss-Newton)
  • If the new cost is higher → reject Δx, increase λ (more like gradient descent)

THE JACOBIAN: Computed by central finite differences — no analytical derivatives needed: J[i][j] ≈ ( r(x + h*ej) - r(x - h*ej) ) / (2h)
