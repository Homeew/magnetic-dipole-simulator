Detailed Description

Sensor models a single 3-axis magnetometer at a fixed location in space.

A 3-axis magnetometer measures all three components of B simultaneously: measurement = (Bx, By, Bz) [T]

In this simulation each sensor is ideal — it sits at a known position and returns the exact field value (before noise is added by GaussianNoise).
